# Психологический тест на тревожность

Мой первый проект на Flask — веб-приложение для прохождения психологического теста.

## Что это

Небольшой сайт, где можно пройти тест на тревожность по шкале GAD-7 (7 вопросов, 4 варианта ответа). После прохождения показывается результат с интерпретацией: минимальная, лёгкая, средняя или высокая тревожность.

Тест не является медицинским диагнозом — это ознакомительный инструмент.

## Зачем я его сделал

Хотел разобраться с Flask, сессиями, localStorage и в принципе с тем, как устроено веб-приложение. Плюс давно интересовала психология, а GAD-7 — это проверенный тест, который используют врачи. Решил совместить.

## Что внутри

- Flask — сервер и роутинг.
- HTML/CSS — вёрстка страниц.
- JavaScript — логика теста, сохранение ответов в localStorage.
- localStorage — хранение имени, ответов и результата (без базы данных).
- Логирование — пишется в system/logs.log.

## Структура

quest/
├── applicationFile/       # основные страницы (главная, регистрация, результат)
├── testQuestions/         # 7 файлов с вопросами теста
├── static/                # картинки
├── system/                # логи
├── launch.py              # точка входа
└── README.md

## Как запустить

1. Установи Python 3.
2. Установи Flask:
   pip install flask
3. Запусти:
   python launch.py
4. Открой в браузере:
   http://localhost:5030

## Как проходит тест

1. Главная страница → кнопка «Пройти тестирование».
2. Если не зарегистрирован — открывается форма регистрации (имя, фамилия — необязательно).
3. Дальше 7 вопросов, на каждом 4 варианта ответа.
4. Ответы сохраняются в localStorage.
5. В конце — результат с баллами и интерпретацией.
